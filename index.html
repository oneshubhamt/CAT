02. VARC — 3 RCs + 8 VA Playbook

VARC · 24 Questions · 40 Mins

3 RCs + 8 VA strategy (17–18 attempts)

99+ Score Math & Target Calibration Illustrative: 17–18 attempts, 13–14 correct, 2 wrong MCQs and 2 wrong TITAs = 37–40 raw marks. Each correct-to-wrong MCQ swing costs 4 marks. Accuracy first; do not force attempts.
Standard (3 RCs): 3 RCs → 4 TITA VA → 4 MCQ VA → 1m Cleanup 20-Q Active Pool

RC: 3-Min Structural Read + Sniper Verification

~8m / RC

Why Neither Extreme Works

Avoid Fast Scan + Jump to Qs Leaves no author map → forces repeated full-paragraph re-reading.
Avoid "Single Laser Read, Never Look Back" Unrealistic for CAT; traps hinge on single qualifiers (mostly vs. solely, correlates vs. causes).
1

Rolling Elimination (45–60s P1 Gate)

Do not compare every passage upfront. Judge P1 by comprehension, not topic. If you cannot state its point after 45–60 seconds, move on; reject more than one if necessary. Default to three readable passages.

2

Pass 1 (3:00–3:30) — Architecture, Not Facts

  • Steady normal-to-brisk pace. Default No-Backtracking Rule on confusing lines: the next sentence may clarify the meaning; briefly reread only if the argument cannot otherwise be followed.
  • Do not memorise names, dates or secondary examples; register where they appear for targeted verification.
  • Tag each paragraph's role in 3–5 words (Old view → Critique → Evidence → Caveat).
  • Read deliberately at pivot words that signal argumentative shifts: however, yet, ironically, although, despite, rather, paradoxically, admittedly, consequently.
3

Answering (4:00–4:30) — Split by Question Type

  • Global Qs (Main Idea / Tone / Purpose / Structure): answer from the mental map first; verify selectively if needed. Practice diagnostic: extensive rereading for the main idea suggests the initial structural read needs improvement.
  • Specific / Inference / EXCEPT: Sniper-jump to exact 3–4 line zone (15–20s).
  • Never force 4/4 on a passage; 3/4 can be preferable if one inference trap is nasty.

45s Two-Option Deadlock

4-Point Checklist

Run one unified 4-point elimination check when down to 2 options:

  1. 01 Extreme / Scope Shift: Uses only, always, never, solely, completely when the author is cautious (tends to, often, primarily).
  2. 02 True in Reality, Unsupported (Alien): Smart real-world concept logically true outside, but absent from the text.
  3. 03 Distortion / Tone & Reversed Causality: correlates ≠ causes; flips cause/effect; confuses critic vs. author; or mismatches tone (e.g., hostile/dismissive option when author is mildly skeptical).
  4. 04 Half-Right Trap: Verbatim first half from text + smuggled unsupported second half.
Hard Bail-Out Rule 45s → stop deliberating; flag unanswered

In cleanup, first save penalty-free TITA answers and any clearer opportunities. Revisit genuinely shortlisted MCQs only if time remains; if two options really are equally likely, the expected raw score is +1 (0.5 × 3 − 0.5 × 1). This is not a guarantee. If elimination is unreliable or sectional accuracy is at risk, leave blank. Clear any speculative saved MCQ before moving on unless deliberately committing to it.

The 4 VA Playbooks

Hard Cap: ~2:00 / Q
VA risk and opportunity — personal hypotheses Calibrate Expectations
1. Potential strengths

Para Summary & Para Completion (MCQs) — Para Completion supplies an ordered paragraph with structural anchors. Compare accuracy against your own mocks.

2. Penalty-free opportunity

Odd One Out (TITA, 0 penalty) — no exact sequence needed, just find the 1 scope-breaker.

3. All-or-nothing sequencing

Para Jumbles (TITA, 0 penalty) — all-or-nothing (flipping 1 pair like 2413 vs 2143 = 0); attempt both as capped 2:00 bonus points.

1. Para Summary

MCQ -1 Structural anchors
  • Method: Read the paragraph once like a miniature RC, then state Subject + Core Claim + Contrast/Condition mentally before viewing options.
  • Trigger: Preserve both sides of any pivot word (however, yet, although).
  • Trap: Verbatim text recycling that zooms into an example, drops a qualifier, or sneaks in outside judgment.

2. Para Completion

MCQ -1 Structural anchors
  • Method: Read the missing sentence FIRST for back-hooks (this, such, they, however, instead) & forward threads.
  • Trigger: Spot the abrupt jump; apply the Double Handshake: [Before] + [Insert] + [After].
  • Trap: Matching the line before the blank while breaking pronoun/logic flow with the line after.

3. Odd Sentence Out

TITA 0 Best Risk-Adjusted ROI
  • Method: Build the 4-sentence coherent paragraph first (find 3 sharing exact subject + angle).
  • Trigger: Separate Topic from Scope; sanity-check by sequencing the remaining 4 lines.
  • Trap: Lexical Decoys — shared buzzwords planted in the odd line to disguise a scope drift.

4. Para Jumbles

TITA 0 Capped Bonus
  • Method: Don't hunt the opener first. Build Mandatory Pairs to narrow the plausible sequences.
  • Triggers: Noun → Pronoun, Cause → Effect, Claim → Contrast, General → Example, Full form → Acronym, Earlier → Later (chronology). Test each pair against the whole paragraph.
  • Cap: At 2:00, lock your best sequence, type it in, and walk away.

Green Flags (Pick Early)

Min 0–4 Scan
  • + Clear data structure: Obvious grid, matrix, Venn diagram, or timeline.
  • + Concrete anchor clues: Fixed numbers or exact positions (not purely relative).
  • + Favorable question stems: Exact values or conditional stems ("If X = 5...").
  • + Familiar archetypes: 2D/3D Tables, Tournaments, Venn, QBR, Linear/Circular, and bar/line charts combined with logical constraints.

Red Flags (Skip / Leave Last)

Avoid Early
  • × Wall of dense abstract text with zero numbers or anchors.
  • × Unbounded case explosion: 4+ early independent branches without elimination.
  • × Heavy messy arithmetic: Compound growth rates, ugly ratios, vague wording.
  • × Hostile stems: All "Min/Max" or "CANNOT be true" questions. Min/max sets can still be favourable when optimisation is your strength and the bounds are tractable.
Caution: Don't auto-pick missing-cell tables just because they look like DI.

The 6-Minute Bail-Out Rule

MIN 6–7 CHECKPOINT

Stay only if: A central constraint is unlocked, or meaningful deductions are accumulating with a credible route to answerable questions.

Bail immediately if: You have no useful representation or new deduction, are circularly rereading, or a better ranked set has a more credible route. Reassess at 4–6 minutes; switch by 6–7 minutes if still stalled.

Mandatory Accuracy Shield

ERROR-LOG TRIGGERS
  1. 1 20–60s Clue Back-Check: Re-read EVERY numbered constraint top-to-bottom against your filled grid before marking a single answer.
  2. 2 Explicit Intermediate Sums: Write every addition out on paper — never mental-total and drop 4 marks on a 10-unit slip.

6 Mechanical Rules to Stop Time Leaks

Execution Discipline
01

45s Ignition & 2.5m Bail-Out

Must have an equation, ratio setup, or path on pad by 45s or leave. In R1, if not in final calculation step at 2.5m, drop & mark for review.

02

Cure the 4–5 Line Arithmetic Allergy

"Pen-Down on Word One": Force yourself to read the first 2 lines of every Arithmetic problem in Round 1 before deciding to skip; dump ratios/timelines immediately on word one. Reframe length as a green flag — don't let 5–10s rapid cycling auto-reject Arithmetic.

03

The Geometry Quarantine

Banned in R1: skip pure Geometry / circle theorems / angle chasing in 10s without drawing. Allowed in R1: pure Mensuration or an obvious 2-step Pythagoras/similarity sitter.

04

Algebra Speed Discipline

Rely on muscle memory (AP/GP, Linear/Quadratics). Only use value plug-in (n=1,2 or x=0,1,-1) or test option boundaries in inequalities (respect the domain and strict/non-strict endpoints), if the technique clicks naturally within 15s — don't force new habits last week.

05

15-Second "Final-8-Words" Audit

Before clicking Save & Next, re-read ONLY the last 8–10 words of the prompt. Silly errors happen at the finish line — catch x vs 2x, "time taken by B alone", or "% more than" before losing 4 marks.

06

On-Screen Calculator Discipline

Use paper for 2-digit math and ratios; touch the mouse-click calculator ONLY for ugly 3-digit division or CI powers. Routine calculator use can waste time.
